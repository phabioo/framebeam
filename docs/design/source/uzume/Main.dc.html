Frame and first start

The FrameBeam Round 5 prototypes, rebuilt as Uzume in the Ma design system. Old files gave structure, copy, states and flows; every colour, type style, rule and component comes from Uzume. Each screen has a Sumi board and a Kinari board below it that imports the Sumi one, so edits apply to both.

Did not fit the design system
01Cards, radii, shadows. AuthCard, choice cards and code wells are gone. Forms sit on the ground; sections are split by space, a SectionLabel and hairlines.
02Cyan and amber. Signal Cyan became Yamabuki, and only on things you can act on. There is no amber: warnings are the Yamabuki “!” square, the offline amber card border is gone.
03Tinted banners. Warn, error and ok boxes became StatusIcon + sentence. The info tone has no equivalent: it is a plain ink-2 sentence.
04Round gamepad pills. Replaced by the system’s GamepadHint. R3 isn’t a GamepadHint key, so Show password is on X. Keyboard keys are the system Kbd since batch 3.
05Server glyph in rows. Old Join, Set up and sidebar rows used it. Uzume keeps it for installer, tray and server About, so rows are text plus StatusLine.
06AppNav extras. Resolved: the system AppNav now has member, THIS PC, ONLINE, bell, menus and compact. 0-4 B shows all four views; every app screen uses compact.
07Toggle switch. Resolved: on/off rows use the system Toggle (0-4 E).
08Select and open menus. Resolved: “Who can join” (8a-5) is a Select, the ⋯ menu in 0-4 D is the system Menu. The ▾ on the sign-in name stays dropped.
09SettingsRow. Resolved: settings use the system SettingsRow and SettingsDisclosure (0-4 E, 3q-app).
10AppBlocks. Metrics with bars, storage bar, lanes and card grids belong to Status (batch 2). The dashed empty box became StateBlock with the ensō.
11Avatar colours. The old hexes became person tokens in join order: Max wasurenagusa, Lena momo, Jonas moegi, Sam fuji.
12Code format. Security codes were spaced (K7Q4 9WMP 2HXD); invite-code style is groups of four joined by hyphens: K7Q4-9WMP-2HXD.
13Invite code prefix. Decided: UZ-, e.g. UZ-8XK2-M4QD. The field accepts spaces, hyphens or none.
14System codes. “DS” and “Nintendo DS” became NDS. Only GB, GBC, GBA, NDS, 3DS.
15Hosts. lena.example.net became 192.0.2.20:8443 (documentation range, like 192.0.2.10). Home server stays server.example.com:8443.
16Library details panel. A 320 px panel would take the open column. Admin details are a numbered section under the table.
17Settings second column. The 300 px sub-page column isn’t a system component. It is drawn as text items with the Yamabuki leading marker, like the nav.
18Sizes. 8a-1 was 1440 × 900 and 8a-2 its 1280 version. Everything is 1280 × 800 now; 8a-2 is the keyboard version. State sheets 8b-5 and 0-4 C are 1040 high to stay legible.
19Light check 8b-6. Every screen now has a Kinari twin, so 8b-6 is the keyboard sign-in.
20Tray states. Cyan / grey / amber became Yamabuki lit (running), dim (stopped), “!” square (needs attention).
21Pixel logo sizes. The 32 and 16 px marks are Pixel assets kept by id; this canvas draws the vector Mark from 20 px up.
22tokens.css. Resolved: the local copy is gone; ds/uzume/tokens.css is now the system’s own file.
