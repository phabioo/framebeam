Did not fit the design system
01Terminal. The server prints plain text, so the terminal is drawn as a stage panel in Mono; the person’s terminal theme decides the colours. Old cyan codes and amber hints are gone; emphasis is weight only.
02MSI chrome. Windows draws the installer: Segoe UI 9 pt, system colours, round radio buttons, the shield. The boards draw it with Uzume tokens at 1:1 and always light; only the two bitmaps and the copy ship. No Sumi twins for 8l.
03MSI size. The client area is 493 × 360: the 493 × 312 bitmap sits above the 48 px button row (the old sheet put the buttons inside the 312).
04Small icons. The title bar and Add/Remove Programs icon need an ICO from the Pixel 32 / 16 tiles; those are kept by id, so they are named here, not drawn.
05Banner tile. AppIcon below 64 px needs Pixel assets, so the 58 px banner shows the vector Mark (36) and ServerGlyph (20) side by side instead of the tile.
06Lane glyphs. Nothing is round but the ensō, so ● ○ ▢ ★ became ■ □ ▣ ◆ (also updated on S2 Blocks).
07Run tabs. RunTabs is only for the in-game side panel, so run pages use Tabs lg; the plugin tab comes last. RunTabs appears in game (4j-app-7, added).
08Plugin surface. There is no component for what a plugin draws; the SoulLink tab marks it with a Mono “Drawn by SoulLink” line over a rule.
09Rules chip. The old cyan plugin chip is a neutral Tag showing the mode. Yamabuki tags stay for New, never for a category.
10Run column. The old 300 px list of runs beside a run is gone; run pages are full width under Tabs, and Ember Route’s details are a section under the Runs table.
11Shield. Buttons that need admin rights show a small outlined placeholder where Windows puts its shield.
12Progress dialog. 8i-3 keeps its step list readable instead of Dialog busy (which dims content); the primary reads “Sharing…” and is disabled.
13Old names. The upgrade dialog (8l-10) still names FrameBeam Player and Hub, because that is what Setup finds on the PC.
14Light check. 8j-1 was the light check; every board except 8l has a Kinari twin.
15Board size. 8l-1 … 3 are 1280 × 1040 to fit four dialogs at 1:1.
