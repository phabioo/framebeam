Randomizer

Randomized game variants: a game plus a recipe (engine version, preset or settings string, seed), built on this PC from your own file and played in its own slot. Randomizing starts from a game page or from a run; the Randomizer plugin has no sidebar row. Every board in Sumi with its Kinari twin below.

Decisions
01Numbering. Revisions stay in the 10 family (10a-1 revises 3c-1, 10e-1 revises 4j-app-3, 10f-4, 10g-1 … 3, 10h-3); the index names the board each one revises. Say if you want them as 3c-5, 4j-app-8 and so on instead.New
02Library. One row per game, with “2 VARIANTS” as the TableRow status, not a row per variant: the Library stays the list of games you own, play time and Continue stay per game, and nothing about a variant is spoiled. Continue resumes the last slot, variant included.New
03Deleting. Delete a variant defaults to Keep saves; kept saves stay with the recipe, so the same world can be built again.New
04Same world. Uzume picks the seed at the start and nobody sees it, the run’s creator neither.New
05Spoiler log. Off by default (Keep a spoiler log). Opens only from a variant’s menu after a confirm; for run variants only after the run ends, and only your own.New
06Own variants. Allowed only when the run says so and the variant uses the run’s pinned engine version.New
07Engine name. “FVX” appears only in 10 px mono lines; normal copy says “the randomizer engine” or “the engine”.New
Did not fit the design system
01SaveRow. The brief names SaveRow; the design system has none. Save versions are drawn as table rows, as in 3c-2.
02Tools in AppNav. The default SERVER group has no Tools. Sheet 5 passes AppNav groups with Tools after Systems & cores; earlier sheets keep the default.
03Toast in narrow panels. Toast is at least 520 wide. State panels drop that the way the stage overlay does; also fixed on 3g-11, 3m-2, 3s-4, 4d-2, 5b-2 and 8e-5, where toasts ran into the next panel.
04Step list. No component for build steps; rows of StatusIcon, Enso and Progress (as in 3 · 12).
05Row focus. Markup rows have no focus state; the focused variant row uses --focus-ring-inset.
06Select in a dialog. An open Select list covers the dialog’s actions, so 10f-2 shows it closed and focused; open lists are on 10b-3 and 10g-2.
