Server commands
uzume-server setup-codeShows the setup code for first setup (8a-4).
uzume-server codeShows the security code to compare when joining (8b-2).
uzume-server reset-adminPrints a one-time admin password; no data is touched.
uzume-server updateUpdates to the newest version on its channel.
uzume-server backupMakes a backup now into the backup folder.
uzume-server restore <file>Replaces everything with that backup; makes a safety backup first.
uzume-server resetDeletes everything: users, games, saves, settings. Asks you to type the server name. Only a backup brings it back.
docker exec -it uzume-server uzume-server reset-adminSame, in the ghcr.io/<owner>/uzume-server container.
