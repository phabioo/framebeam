# protocol

Gemeinsame Protokolldefinition für Hub und Player: OpenAPI für `/api/v1` (HTTPS/JSON), JSON-Schemas für WSS-Nachrichten, `protocol_version` und Handshake. Änderungen am Protokoll landen zusammen mit Hub- und Player-Anpassung.
Unterordner: `openapi/`, `schemas/`.
Architektur: `docs/architektur.md` Abschnitte 3, 13, 14.
