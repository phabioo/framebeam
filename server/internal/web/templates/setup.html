Set up Uzume server

{{if .Body.Local}}

Create the first admin. This form is available from this machine only.

{{else}}

Setup is possible only from the machine the Uzume server runs on. Create the admin there in the console:

uzume-server setup-admin -username <name>

The password is read as a single line from stdin. Afterwards you can sign in here.
