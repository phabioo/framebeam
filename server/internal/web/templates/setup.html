{{if .Body.Local}}

Create the first admin. This form is available from this machine only.

{{else}}

Setup is possible only from the machine the FrameBeam Hub runs on. Create the admin there in the console:

framebeam-hub setup-admin -username <name>

The password is read as a single line from stdin. Afterwards you can sign in here.
